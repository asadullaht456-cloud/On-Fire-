# On Fire - Restaurant Companion App

Welcome to **On Fire**, the ultimate restaurant companion app built for Loopverse 3.0.

## Features
- **Smart Menu**: Browse categories, search, and filter by dietary tags.
- **Customization Engine**: Add-ons, required choices, and special instructions.
- **Smart Cart**: Real-time total calculation with tax/fees and coupon logic.
- **Order Tracking**: Track your meal from kitchen to table.
- **Kitchen View (Demo)**: Simulate kitchen progress and delays.
- **Reorder**: Easily reorder past meals (skips out-of-stock items).

## Setup
```bash
npm install
npm start
```

## Demo Script
1. Open the app and log in (any credentials).
2. Go to the Home screen (Menu). Filter by "Spicy" or "Veg".
3. Select "Flame Grilled Burger" and customize it (add Cheese).
4. Go to Cart, apply coupon "FIRE10", and place the order.
5. In the Confirmation screen, tap "Track Order".
6. In Tracking, tap "Demo: Advance Kitchen Status" to simulate progress. You will see notifications and haptics.
7. Use the "Kitchen" tab to view all active orders and simulate delays.
8. Complete the order, leave a 5-star rating, and view the final receipt.
9. Tap "Reorder" to create a new cart from the receipt.
